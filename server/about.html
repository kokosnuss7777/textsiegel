AI label with textsiegel

How the provider marks the responses of its chatbot as AI-generated and how anyone can check this marking free of charge (Art. 50(2) EU AI Act).

In short

  • Every chatbot response carries an invisible marking behind every sentence. It does not change the visible text.
  • The marking is bound to its sentence: if it is attached to other text or the sentence is changed, the check detects it.
  • Anyone can check on the check page or through the API below – free of charge.
  • Submitted text is only processed for the check and discarded immediately afterwards. It is neither stored nor logged.

Marker format (signpost for verification tools)

Machine-readable: /.well-known/textsiegel.json

  • Carriers: U+200C (ZWNJ) = 0, U+200D (ZWJ) = 1, U+2060 (Word Joiner) = 2.
  • A marking is a run of these characters (base 3, most significant digit first) directly behind a sentence or line end.
  • The first byte of the payload is the version.

Verification API

curl -X POST https://…/v1/verify \
  -H 'content-type: application/json' \
  -d '{"text": "…pasted text…"}'

The response contains the verdict, the technique used, counts per sentence and a signed report with the SHA-256 of the text, the service identifier and a timestamp. Anyone can check the report with the public key from /.well-known/textsiegel-keys.json: the signature is Ed25519 over the canonical JSON (sorted keys) of the field report.

Access for authorities, press and researchers

Checks are free of charge. For general users there is an hourly limit. Market surveillance and law enforcement authorities, media, fact-checkers, trusted flaggers, research and educational institutions and civil society organisations get unlimited access on request. It additionally includes the statistical result, which is less reliable for free-form text and therefore not shown publicly.

Limits

  • Rewording or retyping removes the invisible marking. So do programs that delete all invisible characters.
  • "No marking found" does not mean that a text was written by a human.

For developers

textsiegel is open source (MIT): library, format specification and test vectors for ports to other languages – github.com/kokosnuss7777/textsiegel.
